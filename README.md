# 2D动作战斗系统设计

> 求职方向：系统策划  
> 项目类型：原创 2D 战斗原型  
> 当前阶段：可玩演示 v0.1  
> 核心主题：热量风险、战斗构筑、波次推进

## 项目简介

玩家控制一名近未来回收员，在封闭战斗区域抵御五轮敌群。攻击和击杀会积累热量，热量提高输出，也会让敌人更快、更危险。

玩家需要在以下选择之间保持平衡：

- 保持低热量，稳定处理当前敌人。
- 主动升温，提高伤害和攻击速度。
- 使用冲刺躲避攻击并降低部分热量。
- 在波次结束后选择强化方向。

## 演示内容

- 俯视角移动、瞄准和射击。
- 三类开局战斗回路。
- 四类普通敌人和一个三阶段精英。
- 五轮波次。
- 冲刺、右键范围脉冲、生命值、热量和过热惩罚。
- 击杀掉落、主动拾取和资源回收。
- 十三种构筑升级。
- 战斗统计、暂停和重新开局。
